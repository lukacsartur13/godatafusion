## 1. External asset access — the Phase 6 finding was wrong

Phase 6 recorded "Available: nothing" and authored the whole building
procedurally. Phase 7 re-tested that conclusion against the **official Poly
Haven public API**, and it does not hold: the API answers, needs no key, and
permits commercial use.

| Check | Result |
| --- | --- |
| `GET https://api.polyhaven.com/assets` | **HTTP 200**, 2,344,870 bytes, 2.6 s |
| Catalogue size | 2,366 assets — 991 HDRIs, 854 textures, 521 models |
| Authentication | none required, and none used |
| API key | none exists — Poly Haven ToS §2.3 states one will never be required |
| Commercial use | permitted, ToS §2.1 |
| Required header | a unique `User-Agent` or `Referer`, ToS §2.4 |
| Asset licence | CC0 1.0, stated in the ToS preamble and per asset below |
| Endpoints used | `/assets`, `/info/{id}`, `/files/{id}`, `/types`, `/taxonomy/{type}`, `/categories/{type}` — all six are in the published OpenAPI spec |

Terms were read from the document the API's own spec names as its
`info.termsOfService`, not from a summary:
`https://github.com/Poly-Haven/Public-API/blob/master/ToS.md`. Nothing was
scraped, no undocumented endpoint was called and no licence was assumed.
The pipeline sends `User-Agent: GoDataFusion-AssetPipeline/1.0` on every
request, caches responses on disk and spaces them, per §2.4 and §2.6.

**Attribution.** ToS §2.5 binds use of the *live* API inside a product.
This pipeline runs at build time and the site self-hosts the results, so the
shipped page makes no API call and the clause does not reach it; the assets
themselves are CC0 and carry no attribution requirement "now or ever". The
provenance below is recorded anyway, because a production site should be
able to say where its geometry came from.

## 4. What is NOT available, and stayed procedural

This is the honest half of the audit. Poly Haven is a photogrammetry and
environment library, not a contract-furniture catalogue. Three of the eight
priorities in Part 04 have **no candidate at all**:

| Priority | Asset | Finding |
| --- | --- | --- |
| 02 | Office / task chair | The library contains **no** office task chair. `?t=models` over all 521 models returns one modern seat with a swivel base — a mid-century leather lounge recliner. The procedural task chair is kept. |
| 04 | Meeting table | No contemporary conference table exists. Every table is vintage, rustic or a coffee table. The procedural table is kept and given real oak. |
| 05 | Desk | The only office desk is `metal_office_desk`: *old, vintage, metal, dirty, scratched, industrial*. Kept procedural. |
| — | Graphite metal texture | `?category=metal&condition=clean` returns **zero** assets; every metal in the library is rusted or painted. Metal is therefore analytic — a roughness and a metalness value with no map — which is correct for powder-coated steel anyway. |

The consequence is visible and is stated in the self-review: the six task
chairs at the workstations are the most synthetic objects left in the
building, and no available asset would have fixed that.

## 6. Textures, as shipped

Source is 8K in every case and none of it is shipped. Resolution is decided
per material, not globally: a wall is thirty square metres of one image and
gets 1K; a pendant globe twelve metres away gets 256. Normal maps cap at 512
because a tiling normal is repeated — the wall material repeats every 2.6 m,
so 512 already puts ~197 texels on every metre of wall and a 1440-wide
viewport resolves about 100. That cap alone removed 564 kB.

### KTX2 / Basis

Not shipped, and the reason is a missing tool rather than a decision against it.
KTX2 would cut GPU memory by roughly 4-6x and transfer by a further third.
The encode step is implemented — `python3 tools/textures/pack.py --ktx2` writes
`.ktx2` beside each `.webp` and flags it in the manifest — but it shells out to
Khronos' `toktx`, which is not installed on this machine and is not on npm or
in Blender. No third-party rebuild of it was fetched. The runtime consequence
is measured in the Phase 7 report; the pipeline is ready the day the binary is.
